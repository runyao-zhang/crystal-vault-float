# CrystalFloat · 晶体库的悬浮伴侣

把 [晶体库](https://github.com/runyao-zhang/crystal-vault) 的**边看边记**和**结构窗**
放进一扇能浮在其它窗口之上的独立窗口里——你可以在 Edge 上查资料，那扇窗还压在它上面。

---

## 为什么是「第二个程序」

这不是偷懒，是平台限制。

晶体库的插件跑在 Obsidian 自己的渲染进程里，它造出来的"浮窗"（设置里那三档
全屏 / 浮窗 / 嵌入）**永远跳不出 Obsidian 的窗口**。要压过 Edge、微信、Word，
必须有一个带系统级置顶标志的**原生窗口**——而那只能由另一个进程提供。

Obsidian 的插件沙箱里做不到这件事。整个晶体库源码里对 Electron 的使用只有一处，
就是"把一条网址交给系统浏览器"。

所以：

| | 大小 | 从哪来 |
|---|---|---|
| 晶体库插件 | ~2 MB | Obsidian 社区插件市场（照旧，不用动） |
| **CrystalFloat** | ~107 MB | 本仓的 Release |

装上之后，插件会**自动找到**它，你不需要填任何路径。

## 安装

1. 从 [Releases](../../releases/latest) 下 `CrystalFloat-<版本>-x64.exe`
2. 双击。**免管理员**，可以选安装目录
3. 看到 Windows 的蓝色拦截框时：点「**更多信息**」→「**仍要运行**」

### ⚠️ 关于那个蓝色拦截框

这个程序**没有代码签名**（签名证书要按年付费）。所以 Windows SmartScreen 会在
第一次运行时拦一下。

```
┌─────────────────────────────────────────┐
│  Windows 保护了你的电脑                  │
│  Microsoft Defender SmartScreen 阻止了  │
│  一个无法识别的应用启动…                 │
│                                         │
│         [更多信息]  [不运行]             │
└─────────────────────────────────────────┘
              ↓ 点「更多信息」
┌─────────────────────────────────────────┐
│          [仍要运行]  [不运行]            │
└─────────────────────────────────────────┘
```

这一步**只需要做一次**。安装包和便携版都一样。

如果你不想装东西：下 `CrystalFloat-portable-<版本>.exe`，它是个自解压的单文件，
解到哪儿就在哪儿跑，不进「添加或删除程序」。

## 用

在 Obsidian 里打开命令面板（`Ctrl+P`），有两条：

- **晶体库：独立窗口：边看边记**
- **晶体库：独立窗口：结构窗**

窗口顶栏有一条拖拽区，右边三个按钮是**置顶开关 / 最小化 / 关闭**。

关掉 Obsidian，悬浮窗会跟着关掉——它没有数据源就跑不了。反过来，**关掉悬浮窗不会
影响 Obsidian**。

---

## 置顶能压住什么，压不住什么

诚实清单：

**能压住**：Edge、Chrome、微信、QQ、Word、资源管理器这类常规窗口，包括最大化的。

**压不住**：
- 独占全屏的应用（比如全屏播放的视频、全屏游戏）
- **另一个同样是置顶的窗口**——同档相撞时谁后激活谁赢。你机器上如果有
  Raycast（它默认置顶）、或者某些截图/录屏工具，就会碰到这条
- UAC 提权弹窗（那个在安全桌面上，谁都压不住）
- 自动隐藏时的任务栏

如果哪天它被压到下面去了，点一下窗口顶栏的「置顶」关掉再打开，或者最小化再还原。

## 几条已知的折价

**这些是真的，不是免责声明。**

1. **在悬浮窗里编辑卡片正文，用的是纯文本框**，不是 Obsidian 那个实时预览编辑器。
   原因是 Obsidian 的编辑器组件跨不了进程。翻 PDF、拖卡片、写笔记都照常，
   只有"编辑正文时的编辑体验"这一项降级。

2. **悬浮文档里的 `[[双链]]` 和 callout 渲染成纯文本**，Dataview 之类插件提供的
   markdown 扩展也不生效。悬浮窗用的是自带的渲染器。

3. **不要同时在两边拖同一张卡**。卡片坐标是防抖写入、没有基线比对的，
   两边同时动手会有一边被覆盖。串行操作（一边改完再动另一边）没问题——
   改动会通过实时推送同步过去。

4. **Obsidian 中途退出时，悬浮窗里还没写回的改动会丢**，而且**不会自动重试**。
   这是刻意的：自动重试会把旧内容覆盖到新内容上。窗口会弹一句明确的提示，
   而不是装作什么都没发生。

## 从源码构建

```bash
npm ci
npm run dist        # 出 dist/float-dist/ 下的安装包
```

需要 Node 20+。第一次会下载 Electron 与 NSIS 工具链，几百 MB。

> ⚠️ **本仓的 `src/` 和 `floating/` 是产物**，由
> [ari-crystal](https://github.com/runyao-zhang/ari-crystal) 的
> `scripts/land-float.mjs` 同步过来。改这里会在下次同步时被覆盖——请改上游。
